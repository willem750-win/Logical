Memory

Goal: store numbers at an address in a memory and find them again later, just like a computer does.

▶ Open this example

Address and content

A memory is like a cabinet with numbered drawers. The number of a drawer is the address, what is in it is the content. This memory block has 32 drawers (address 0 to 31) and each drawer holds a number from 0 to 15.

  • The counter at the top chooses the address. The bottom push button counts one address further, the top one resets to 0 (see lesson 8). The top display shows the address.
  • With the DIP switch you set a number (8, 4, 2, 1). With its button you write the number into the chosen drawer.
  • The bottom display shows the content of the chosen address.

Try it

  1. Start the simulation. The address is 0.
  2. Turn on 4 and 1 on the DIP switch (= 5) and press the button of the DIP switch. The bottom display shows 5.
  3. Count one address further: the content of address 1 is still 0.
  4. Write another number there, for example 9 (8 + 1).
  5. Reset the counter to 0: the display shows 5 again. The memory has remembered it.

Exercise

Store the numbers 3, 1, 4, 1 and 5 at the addresses 0 to 4. Then reset the counter to 0 and step through the addresses. Do you read the numbers back in the right order?

Solution

At each address: set the number on the DIP switch (3 = 2 + 1, 1 = 1, 4 = 4, 5 = 4 + 1), press the button of the DIP switch, and then go one address further with the counter. After a reset the display shows the stored number at each step: 3, 1, 4, 1, 5.
