Memory

Goal: store numbers at an address in a memory and find them again later, just like a computer does.

▶ Open this example

Address and content

A memory is like a cabinet with numbered drawers. The number of a drawer is the address, what is in it is the content. This memory block has 32 drawers (address 0 to 31) and each drawer holds a number from 0 to 15.

  • The counter at the top chooses the address. The top push button (Re) resets to 0, the second (Te) counts one address further (see lesson 8). The top display shows the address.
  • With the DIP switch you set a number (8, 4, 2, 1). Each output goes with its own wire to a data input D8, D4, D2 or D1 of the memory. Press the bottom push button (on S, write) to store the number in the chosen drawer.
  • The bottom display shows the content of the chosen address.

Counter and memory together

The counter and the memory each have their own job. Think of a cabinet with drawers:

  • The counter is the hand that pulls a drawer open. Its four outputs T8, T4, T2 and T1 go to the address inputs A8, A4, A2 and A1 of the memory: the number in the counter is the number of the open drawer. Te opens the next drawer, Re goes back to drawer 0. The fifth address input A16 adds 16: with the switch on it (the third from the top) you reach drawers 16 to 31.
  • The memory is the cabinet itself. It always shows what is in the open drawer: on the outputs G8, G4, G2 and G1, on the four lamps in the block and on the bottom display.
  • The DIP switch is what you hold in your hand: a number ready on D8 to D1. Only when you press S do you put it into the open drawer. What was in it before is then gone.

Address or content? The top display shows which drawer is open, the bottom one what is in it. If the top shows 1 and the bottom 0, that is not an error: nothing has been written in drawer 1 yet.

A computer works the same way: a counter, the program counter, points to the next address in the memory each time, and the memory returns what is stored there. That is how a computer reads its program step by step.

Try it

  1. Start the simulation. The address is 0.
  2. The DIP switch is set to 5 (4 + 1). Press the write button S: the bottom display shows 5.
  3. Count one address further: the content of address 1 is still 0.
  4. Write another number there, for example 9 (8 + 1).
  5. Reset the counter to 0: the display shows 5 again. The memory has remembered it.

Exercise

Store the numbers 3, 1, 4, 1 and 5 at the addresses 0 to 4. Then reset the counter to 0 and step through the addresses. Do you read the numbers back in the right order?

Solution

At each address: set the number on the DIP switch (3 = 2 + 1, 1 = 1, 4 = 4, 5 = 4 + 1), press the write button S, and count one address further. After a reset the display shows the stored number at each step: 3, 1, 4, 1, 5.
