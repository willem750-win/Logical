LogicRun: programming in steps

LogicRun is a block that you do not wire but program. You write a series of steps; each step switches a number of outputs on. That way you build a traffic light, a running light or a counter without using a single gate.

For advanced users: LogicRun is an extension. Start with it once you know lessons 1 to 11 of the learning path: there you first learn switching with gates and wires. Lessons 12 to 17 are about LogicRun.

The block

  • Left: 4 inputs DIN1 to DIN4. Under each input you see what it does (see The inputs).
  • Right: 8 outputs UIT0 to UIT7, each with a small lamp that turns red when the output is on.
  • Below: T1 and T2, two connections for a display. The red digit next to them is what the display shows (see Displays).
  • At the bottom the step the program is at, or stopped.

You connect the block with ordinary wires: switches and sensors to the inputs, the outputs to lamps, relays, a buzzer or the inputs of other components.

  1. Click LogicRun in the button bar. The LogicRun window opens next to Logic.
  2. If there is no block on the panel yet, click Put the block on the panel and then on the panel.

There can be only one LogicRun block on a panel. Double-click the block, or choose Edit program... in the right-click menu, to open the window. The right-click menu also lets you lock the block or delete it.

Making a program

  • Each row in the table is a step. The program runs the steps from top to bottom.
  • Click a circle to switch that output on (red) or off (white) in that step.
  • time x says how long the step lasts, in times the step time. With a step time of 500 ms, a step with time 6 lasts three seconds.

A program has at most 64 steps.

Waiting for an input or for pulses

A step normally lasts time x times the step time. In the wait for column you can make a step wait instead. Click in that column and choose:

ChoiceThe step lasts until ...For example
Nonethe time is up (as usual)a traffic light
Until input onthe chosen input is ona limit switch: the cart drives until it reaches the wall
Until input offthe chosen input is offwaiting until someone releases a button
Until number of pulses on inputthat many pulses have arrived on the inputcounting boxes: after 5 boxes the belt stops

A step that waits has no time: the time x column then shows a dash. At the top of the window and at the bottom of the block you see what the step is waiting for and how many pulses have been counted.

Tip: set an input that a step waits for to - in the input functions, so that it does not also start or stop the program. To see the pulses too, also connect the input to the counter and its display (see lesson 14).

Displays: T1 and T2

Below UIT7 the block has two extra connections for a display, just like the output of a counter. They read the outputs as a binary number:

ConnectionReadsShows
T1UIT0 to UIT3 (UIT0 = 1, UIT1 = 2, UIT2 = 4, UIT3 = 8)0 to 9 and A to F
T2UIT4 to UIT7 (UIT4 = 1, UIT5 = 2, UIT6 = 4, UIT7 = 8)0 to 9 and A to F

In the window, the T1 and T2 columns show the digit of each step. Click such a digit and choose another one: LogicRun then switches the 4 outputs on or off itself. Next to each digit in the menu you see the 4 bits, e.g. 5 = 0101. The normal outputs keep working, so you can drive lamps and a display at the same time.

Put two displays side by side, T2 on the left and T1 on the right, to get a two-digit number (from 00 to FF).

The inputs

Most functions react at the moment the input switches on: use a push button for them. For a switch there is the on/off function.

FunctionWhat happens when the input switches on?
start/stopIf the program is not running, it starts; if it is running, it pauses.
resetThe program goes to the first step.
+1The program goes one step further.
on/offThe program runs as long as the input is on. When it goes off, the program stops and all outputs go off (handy with a switch).
-Nothing: the input is not used.

Examples

ExampleOutputs
Traffic lightUIT0 red, UIT1 amber, UIT2 green.
Running lightUIT0 to UIT7 switch on one by one.

4-bit counterUIT0 to UIT3 count in binary from 0 to 15 (UIT0 = 1, UIT1 = 2, UIT2 = 4, UIT3 = 8).

The same program as in lesson 17: connect UIT0 to V and UIT1 to A of a cart, Start to DIN2, Tel to DIN3 and Finish to DIN4.

Tip: loading an example replaces the program. With Ctrl+Z you get the previous program back.

Saving

The program is saved together with the panel in the panel file (.lpl). Undo also works for changes to the program. An older version of Logic skips the LogicRun block.
