Processing

Processing components take signals from the inputs, work on them and pass the result on to the outputs.

Logic gates

A gate has inputs on the left and an output on the right. The symbols in the program carry the Dutch names EN (AND), OF (OR) and NIET (NOT).

AND gate

The output is only on when both inputs are on.

One input; the output is the opposite of the input.

Input N1Output N
01

Tip: by combining gates you can make any logic function, for example a NOT gate after an AND gate (a NAND function).

Counter block

Counts the pulses on its count input and passes the count on in binary on four outputs.

ConnectionMeaning
TeCount input: every pulse moves the counter one step on.
ReReset: sets the counter back to 0.
8 4 2 1The count as a binary number (0 to 15).

Connect the outputs to lamps or to a display to see the count. A push button or pulse generator on the count input makes the counter run.

Memory block

A memory with 32 locations (address 0 to 31). Each location holds a number from 0 to 15. When placed, every location contains 0.

ConnectionMeaning
A 8 4 2 1Address inputs at the top: choose the memory location in binary.
Button A16The button at the top left adds 16 to the address, for locations 16 to 31. The chosen address is shown in the block (ADRES = …).
writeWrite input on the left: connect a DIP switch here. When you press the DIP switch's button, its number is stored at the chosen address.
G 8 4 2 1The content of the chosen location as a binary number, at the bottom.

The memory panel shows a worked-out example with a counter as address and displays for address and content.
