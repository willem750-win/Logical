Working with objects

All components on the panel work the same way: drag to move, right-click for the menu.

Mouse

ActionResult
Drag with the left mouse buttonMoves the component. Wires move along. With guide lines on you see helper lines.
Click on the symbolOperates an input component, such as switching a switch or pressing a push button.
Right-clickOpens the component's menu (see below).
Hold the mouse stillShows the hint with name and state, if Information on is chosen.

Right-click menu

Menu itemWhat does it do?
Lock / UnlockA locked component can no longer be moved or changed and has no right-click menu any more. Handy when the circuit is finished.
Change nameGives the component its own name, which appears in the hint and the status bar.
Information on / offTurns the hint of this component on or off.
Select object / Deselect objectSelects the component in order to delete it.

Deleting a component

  1. Right-click the component and choose Select object.
  2. Click Delete selected object among the editing buttons. The hint of that button shows which object will be deleted.

Keys

KeyWhat does it do?
F1Opens the help about the component or button under the mouse.
