The half adder

Goal: add two binary digits (bits) with an XOR gate and an AND gate.

▶ Open this example

Adding in binary

A computer calculates with only 0 and 1. When you add two bits, there are only four possibilities: 0 + 0 = 0, 0 + 1 = 1, 1 + 0 = 1 and 1 + 1 = 10 (two in binary). With 1 + 1 you write 0 and carry 1, just like 5 + 5 = 10 in the decimal system. That carried digit is the carry (C). The other digit is the sum (S).

Two gates, two columns

Compare the sum column with the tables under Processing: it is exactly an XOR gate, which is on when exactly one input is on. The carry column is an AND gate: only on when both inputs are on. So both switches go to both gates.

  1. Start the simulation and turn the switches on and off, one at a time.
  2. For each position, check the table: is the LED on, the lamp, or both?
  3. Read the lamp and the LED together as a binary number: lamp = 2, LED = 1.

Assignment

Replace the XOR gate with an ordinary OR gate. For which position of the switches is the sum no longer correct?

Solution

For 1 + 1. The OR gate then also turns the LED on, so the LED and the lamp are both on: that is 11, or three. But 1 + 1 is two (10). The sum may only be on when exactly one input is on, and that is what the XOR gate does.

Why “half”? This circuit only adds two bits. To add larger numbers you also have to include the carry from the previous column. With two half adders and an OR gate you build a full adder, the basis of the arithmetic in every computer.
