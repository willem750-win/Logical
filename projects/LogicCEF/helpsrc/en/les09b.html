A light show

Goal: use a memory as a program: a counter runs through the drawers and each drawer is one picture of the light show. With the address input A16 you choose between two programs.

▶ Open this example

How it works

  • The pulse generator gives pulses on Te: the counter counts 0, 1, 2 … 15 and then starts again (as in lesson 8). The top push button (Re) resets it to 0.
  • The outputs T8 to T1 go to the address inputs A8 to A1: the counter chooses the drawer (as in lesson 9).
  • The outputs G8, G4, G2 and G1 of the memory drive four lamps. Each drawer is a picture: a lamp is lit when its bit is 1. Drawer 0 holds 1, so only lamp 1 is lit.
  • The switch on A16 chooses the program: open = drawers 0 to 15, closed = drawers 16 to 31.
ProgramDrawersWhat you see
1 (A16 open)0 – 15a running light: 1, 2, 4, 8, 4, 2, 1, …
2 (A16 closed)16 – 31flashing: outside/inside (9, 6), all on/off (15, 0), top/bottom (3, 12) and alternating (5, 10)
This is how a computer works: the counter is the program counter, which runs through the memory step by step; the memory holds the program. With one more address line (A16) a completely different program is ready. Such a half of a memory is called a bank.

Try it

  1. Start the simulation and click the box of the pulse generator: the running light starts.
  2. Close the switch on A16: the counter keeps running, but now through the second program.
  3. Right-click the pulse generator and choose another frequency: the show goes faster or slower.

Exercise

Make your own light show in drawers 16 to 31. Stop the pulse generator, close the switch on A16 and press Re. Set a picture with the DIP switch, press the write button (S) and count one drawer further with the pulse generator or with an extra push button on Te. Then save the panel: the contents of the memory are saved too.

Solution

An example that turns the lamps on one by one and off again: 1, 3, 7, 15, 7, 3, 1, 0 (twice). Each number is a sum: 3 = 2 + 1, 7 = 4 + 2 + 1, 15 = 8 + 4 + 2 + 1. To write faster, leave the pulse generator off and let the counter count by hand.
