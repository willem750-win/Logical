The NOT gate

Goal: invert a signal with a NOT gate, and read a truth table.

▶ Open this example

How it works

A NOT gate has one input and one output. The output is always the opposite of the input. In a truth table you list all possibilities below each other:

Push button (input)Lamp (output)
0 – released1 – lit
1 – pressed0 – off

Build it yourself

  1. Place a push button, a NOT gate and a lamp next to each other.
  2. Wire from the push button to input N1 of the gate.
  3. Wire from output N of the gate to the lamp.

Exercise

A fridge light is on when the door is open. The door switch is pressed when the door is closed. Which circuit do you need?

Solution

Exactly this example: door closed = button pressed = lamp off; door open = button released = lamp on. Without the NOT gate the light would be on precisely when the door is closed.
