The flip-flop remembers

Goal: use an SR flip-flop to remember a short press on a button, like an alarm that keeps going.

▶ Open this example

A gate forgets, a flip-flop remembers

With a gate, the output only depends on the inputs right now. Release the button and the lamp goes off. A flip-flop has a memory of one bit: output Q stays 1 or 0, even when the inputs go off again.

S (top button)R (bottom button)Q (LED)
00stays as it was
101 (set)
010 (reset)
11forbidden; in Logic R wins: 0
  1. Start the simulation. The LED is off: a new flip-flop starts with Q = 0.
  2. Briefly press the top button (S). The LED comes on and stays on when you release it.
  3. Press S again: nothing changes, Q is already 1.
  4. Press the bottom button (R). Now the LED goes off and stays off.

An alarm

This is how an alarm works: a door contact or motion sensor only gives a short signal on S, but the siren must keep sounding until someone presses reset. Feel free to replace the LED with a buzzer.

Exercise: counting to three

Right-click the flip-flop and choose T. Now Q toggles on every press of the button: the flip-flop divides the number of presses by two. Add a second flip-flop, also of type T. How do you connect them so that two lamps count in binary: 0, 1, 2, 3 and back to 0?

Solution

The push button goes to T of the first flip-flop. Its Q goes to a lamp with value 1. Its Q̅ (not-Q) goes to T of the second flip-flop, and Q of that second flip-flop goes to a lamp with value 2. Each time the first lamp goes from 1 to 0, Q̅ comes on and the second flip-flop toggles: that is the carry, just like in the half adder.

Memory: the working memory of a computer consists of billions of such memory cells. A processor stores numbers with D flip-flops, and counts with T flip-flops.
