Installing Logic

Logic is free and runs on a Windows PC and on Linux. You can install it or, without installing, simply unpack it. You do not need administrator rights.

Download

You will find the latest version on SourceForge and on GitHub. Choose the file for your computer:

ComputerFileWhat is it?
WindowsLogic-<version>-setup.exeInstaller (recommended).
WindowsLogic-<version>-win64.zipNo installation: unpack and start.
Linux (Debian, Ubuntu, Mint ...)logical_<version>_amd64.debInstallation package (recommended).
Other LinuxLogic-<version>-linux-x86_64.tar.gzNo installation: unpack and start.

Mac, tablets and smartphones are not supported.

Windows: install

  1. Double-click Logic-<version>-setup.exe in your Downloads folder.
  2. Do you see a blue window Windows protected your PC? Click More info and then Run anyway. Windows shows this message for programs that have not been downloaded often yet.
  3. Follow the steps of the installer. Logic appears in the Start menu and, if you tick the option, on the desktop.

You install a newer version the same way, over the old one. Your own panels and settings are kept.

Windows: without installing (zip)

Useful if you are not allowed to install anything, for example on a school laptop, or if you want to carry Logic on a USB stick.

  1. Right-click Logic-<version>-win64.zip and choose Extract All.... Choose a folder you can write to, for example Documents\Logic or a USB stick.
  2. Open the extracted folder and double-click logicCEF.exe. At the blue message, click More info and Run anyway again.
Note: do not start Logic directly from the zip without unpacking it. Logic cannot save your panels then, and the help does not work.

Linux

  1. Install the package: double-click logical_<version>_amd64.deb (Software Install) or type in a terminal:
    sudo apt install ./logical_<version>_amd64.deb
  2. Start Logic from the menu, under Education, or type logical.

Without installing: unpack Logic-<version>-linux-x86_64.tar.gz in your home folder and start ./logicCEF in the unpacked folder.

On Linux the help opens in your normal browser.

Where are my panels?

A panel you save goes to Logic's panels folder by default:

Installed withFolder
Windows installer%LOCALAPPDATA%\Programs\Logic\panels
Zipthe panels folder inside the folder where you unpacked Logic
Linux package~/.local/share/logical/panels

Do you need to hand in a panel? Save it with Save somewhere you can easily find it again, such as Documents, and send that .lpl file.
