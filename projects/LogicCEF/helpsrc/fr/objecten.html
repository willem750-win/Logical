Manipuler les objets

Tous les composants du panneau fonctionnent de la même manière : glisser pour déplacer, clic droit pour le menu.

Souris

ActionRésultat
Glisser avec le bouton gaucheDéplace le composant. Les fils suivent. Avec les guides actifs, des lignes d’aide apparaissent.
Cliquer sur le symboleCommande un composant d’entrée, par exemple basculer un interrupteur ou enfoncer un bouton-poussoir.
Clic droitOuvre le menu du composant (voir ci-dessous).
Laisser la souris immobileAffiche l’info-bulle avec le nom et l’état, si Infos on est choisi.

Menu contextuel

Élément de menuQue fait-il ?
Verrouiller / DéverrouillerUn composant verrouillé ne peut plus être déplacé ni modifié et n’a plus de menu contextuel. Pratique quand le circuit est terminé.
Changer le nomDonne au composant un nom propre, qui apparaît dans l’info-bulle et la barre d’état.
Infos on / offActive ou désactive l’info-bulle de ce composant.
Sélectionner un objet / Désélectionner l’objetSélectionne le composant pour pouvoir le supprimer.

Supprimer un composant

  1. Faites un clic droit sur le composant et choisissez Sélectionner un objet.
  2. Cliquez sur Supprimer l’objet sélectionné parmi les boutons de modification. L’info-bulle de ce bouton indique l’objet qui sera supprimé.
