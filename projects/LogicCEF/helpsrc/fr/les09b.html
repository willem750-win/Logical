Un spectacle de lumière

Objectif : utiliser une mémoire comme programme : un compteur parcourt les tiroirs et chaque tiroir est une image du spectacle. Avec l’entrée d’adresse A16, vous choisissez entre deux programmes.

▶ Ouvrir cet exemple

Fonctionnement

  • Le générateur d’impulsions donne des impulsions sur Te : le compteur compte 0, 1, 2 … 15 puis recommence (comme dans la leçon 8). Le bouton-poussoir du haut (Re) le remet à 0.
  • Les sorties T8 à T1 vont vers les entrées d’adresse A8 à A1 : le compteur choisit le tiroir (comme dans la leçon 9).
  • Les sorties G8, G4, G2 et G1 de la mémoire commandent quatre lampes. Chaque tiroir est une image : une lampe s’allume quand son bit vaut 1. Le tiroir 0 contient 1, donc seule la lampe 1 est allumée.
  • L’interrupteur sur A16 choisit le programme : ouvert = tiroirs 0 à 15, fermé = tiroirs 16 à 31.
ProgrammeTiroirsCe que vous voyez
1 (A16 ouvert)0 – 15un chenillard : 1, 2, 4, 8, 4, 2, 1, …
2 (A16 fermé)16 – 31clignotements : extérieur/intérieur (9, 6), tout allumé/éteint (15, 0), haut/bas (3, 12) et en alternance (5, 10)
C’est ainsi que fonctionne un ordinateur : le compteur est le compteur ordinal, qui parcourt la mémoire pas à pas ; la mémoire contient le programme. Avec une ligne d’adresse de plus (A16), un tout autre programme est prêt. Une telle moitié de mémoire s’appelle une banque.

Essayez

  1. Démarrez la simulation et cliquez sur le boîtier du générateur d’impulsions : le chenillard démarre.
  2. Fermez l’interrupteur sur A16 : le compteur continue, mais maintenant dans le deuxième programme.
  3. Clic droit sur le générateur d’impulsions et choisissez une autre fréquence : le spectacle va plus vite ou plus lentement.

Exercice

Créez votre propre spectacle dans les tiroirs 16 à 31. Arrêtez le générateur d’impulsions, fermez l’interrupteur sur A16 et appuyez sur Re. Préparez une image avec l’interrupteur DIP, appuyez sur le bouton d’écriture (S) et avancez d’un tiroir avec le générateur d’impulsions ou avec un bouton-poussoir supplémentaire sur Te. Enregistrez ensuite le panneau : le contenu de la mémoire est enregistré aussi.

Solution

Un exemple qui allume les lampes une à une puis les éteint : 1, 3, 7, 15, 7, 3, 1, 0 (deux fois). Chaque nombre est une somme : 3 = 2 + 1, 7 = 4 + 2 + 1, 15 = 8 + 4 + 2 + 1. Pour écrire plus vite, laissez le générateur arrêté et faites compter le compteur à la main.
