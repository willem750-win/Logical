La mémoire

Objectif : enregistrer des nombres à une adresse dans une mémoire et les retrouver plus tard, comme le fait un ordinateur.

▶ Ouvrir cet exemple

Adresse et contenu

Une mémoire ressemble à une armoire à tiroirs numérotés. Le numéro d’un tiroir est l’adresse, ce qu’il contient est le contenu. Ce bloc mémoire a 32 tiroirs (adresses 0 à 31) et chaque tiroir contient un nombre de 0 à 15.

  • Le compteur en haut choisit l’adresse. Le bouton-poussoir du bas avance d’une adresse, celui du haut remet à 0 (voir la leçon 8). L’afficheur du haut montre l’adresse.
  • Avec le commutateur DIP, vous préparez un nombre (8, 4, 2, 1). Son bouton écrit le nombre dans le tiroir choisi.
  • L’afficheur du bas montre le contenu de l’adresse choisie.

Essayez

  1. Démarrez la simulation. L’adresse est 0.
  2. Activez 4 et 1 sur le commutateur DIP (= 5) et appuyez sur son bouton. L’afficheur du bas montre 5.
  3. Avancez d’une adresse : le contenu de l’adresse 1 est encore 0.
  4. Écrivez-y un autre nombre, par exemple 9 (8 + 1).
  5. Remettez le compteur à 0 : l’afficheur montre de nouveau 5. La mémoire s’en est souvenue.

Exercice

Enregistrez les nombres 3, 1, 4, 1 et 5 aux adresses 0 à 4. Remettez ensuite le compteur à 0 et parcourez les adresses. Relisez-vous les nombres dans le bon ordre ?

Solution

À chaque adresse : préparez le nombre sur le commutateur DIP (3 = 2 + 1, 1 = 1, 4 = 4, 5 = 4 + 1), appuyez sur son bouton, puis avancez d’une adresse avec le compteur. Après une remise à 0, l’afficheur montre à chaque pas le nombre enregistré : 3, 1, 4, 1, 5.
