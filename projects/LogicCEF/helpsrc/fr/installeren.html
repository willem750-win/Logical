Installer Logic

Logic est gratuit et fonctionne sur un PC Windows et sous Linux. Vous pouvez l'installer ou, sans installation, simplement le décompresser. Aucun droit d'administrateur n'est nécessaire.

Télécharger

Vous trouverez la dernière version sur SourceForge et sur GitHub. Choisissez le fichier pour votre ordinateur :

OrdinateurFichierQu'est-ce que c'est ?
WindowsLogic-<version>-setup.exeProgramme d'installation (conseillé).
WindowsLogic-<version>-win64.zipSans installation : décompresser et lancer.
Linux (Debian, Ubuntu, Mint ...)logical_<version>_amd64.debPaquet d'installation (conseillé).
Autre LinuxLogic-<version>-linux-x86_64.tar.gzSans installation : décompresser et lancer.

Mac, tablettes et smartphones ne sont pas pris en charge.

Windows : installer

  1. Double-cliquez sur Logic-<version>-setup.exe dans votre dossier Téléchargements.
  2. Une fenêtre bleue Windows a protégé votre ordinateur apparaît ? Cliquez sur Informations complémentaires, puis sur Exécuter quand même. Windows affiche ce message pour les programmes qui n'ont pas encore été souvent téléchargés.
  3. Suivez les étapes du programme d'installation. Logic apparaît dans le menu Démarrer et, si vous cochez l'option, sur le bureau.

Une version plus récente s'installe de la même façon, par-dessus l'ancienne. Vos panneaux et vos réglages sont conservés.

Windows : sans installation (zip)

Pratique si vous n'avez pas le droit d'installer, par exemple sur un portable de l'école, ou si vous voulez emporter Logic sur une clé USB.

  1. Cliquez avec le bouton droit sur Logic-<version>-win64.zip et choisissez Extraire tout.... Choisissez un dossier où vous pouvez écrire, par exemple Documents\Logic ou une clé USB.
  2. Ouvrez le dossier extrait et double-cliquez sur logicCEF.exe. Au message bleu, cliquez à nouveau sur Informations complémentaires et Exécuter quand même.
Attention : ne lancez pas Logic directement depuis le zip sans le décompresser. Logic ne peut alors pas enregistrer vos panneaux et l'aide ne fonctionne pas.

Linux

  1. Installez le paquet : double-cliquez sur logical_<version>_amd64.deb (Installation de logiciels) ou tapez dans un terminal :
    sudo apt install ./logical_<version>_amd64.deb
  2. Lancez Logic depuis le menu, sous Éducation, ou tapez logical.

Sans installation : décompressez Logic-<version>-linux-x86_64.tar.gz dans votre dossier personnel et lancez ./logicCEF dans le dossier décompressé.

Sous Linux, l'aide s'ouvre dans votre navigateur habituel.

Où sont mes panneaux ?

Un panneau que vous enregistrez va par défaut dans le dossier panels de Logic :

Installé avecDossier
Programme d'installation Windows%LOCALAPPDATA%\Programs\Logic\panels
Ziple dossier panels dans le dossier où vous avez décompressé Logic
Paquet Linux~/.local/share/logical/panels

Vous devez rendre un panneau ? Enregistrez-le avec Enregistrer à un endroit facile à retrouver, comme Documents, et envoyez ce fichier .lpl.
