Ein echtes Arduino-Board

Logic kann einen echten Arduino Uno (oder Nano) über das USB-Kabel steuern. Ein echter Taster auf dem Board bedient dann eine Schaltung in Logic, und Logic lässt eine echte LED auf dem Board leuchten. So bauen Sie eine Schaltung zuerst auf dem Bildschirm und sehen sie danach wirklich arbeiten.

Was brauchen Sie?

  • Einen Arduino Uno oder Nano (oder einen Klon) mit USB-Kabel, ein Steckbrett, einige LEDs, Widerstände von 220 Ω und Taster. Ein Starterkit enthält das alles.
  • Die kostenlose Arduino IDE, um einmal das Programm StandardFirmata auf das Board zu spielen: Datei › Beispiele › Firmata › StandardFirmata, dann Hochladen. Logic spricht mit dem Board in der Sprache von Firmata; danach brauchen Sie die Arduino IDE nicht mehr.
  • Günstige Klone verwenden oft einen CH340-Chip für USB. Windows installiert den Treiber meist selbst; sonst finden Sie ihn bei der Arduino IDE.

Die zwei Bauteile

TasteNameWas ist das?
Arduino-EingangEin Taster mit zwei Klemmen im Stromkreis, wie der gewöhnliche Taster. Er ist geschlossen, solange der echte Taster auf dem Board gedrückt ist. Schließen Sie den Taster zwischen Pin (standardmäßig D2) und GND an; ein Widerstand ist nicht nötig, Logic schaltet den internen Pull-up des Pins ein. Ohne Board drücken Sie mit der Maus darauf.
Arduino-AusgangEine 5-V-Lampe mit zwei Klemmen. Leuchtet sie (z. B. am Ausgang eines Gatters), setzt Logic den echten Pin hoch (5 V), sonst niedrig. Schließen Sie am Pin (standardmäßig D13) eine LED mit einem Widerstand von 220 Ω nach GND an. An D13 sitzt auch schon eine kleine LED auf dem Board selbst.

Mit Rechtsklick › Pin des Arduino wählen Sie einen anderen Pin: D2 bis D13 (und für einen Eingang auch A0 bis A5). Beide Bauteile zählen in der Wahrheitstabelle.

Fehlen die zwei Tasten? Sie stehen in der Bauteilleiste ab der Stufe Fortgeschritten: Wählen Sie Panelwahl › Stufe.

Verbinden

  1. Stecken Sie das Board in einen USB-Anschluss.
  2. Klicken Sie in der oberen Leiste auf Arduino-Board (links von der Lupe).
  3. Wählen Sie den Port (z. B. COM3, unter Linux /dev/ttyACM0) und klicken Sie auf Verbinden. Das Board startet kurz neu; nach zwei Sekunden steht dort Verbunden ... (Firmata 2.5).
  4. Starten Sie die Simulation und drücken Sie den echten Taster.

Achtung: Ein Pin liefert höchstens etwa 20 mA. Eine LED mit Widerstand ist in Ordnung; eine Lampe, einen Motor oder ein Relais steuern Sie über einen Transistor oder ein Relaismodul (siehe Lektion 42). Schließen Sie nie 230 V an das Board an.

Ein echter Servo

Ein Servomotor auf dem Panel kann einen echten Servo mitdrehen lassen. Rechtsklick auf den Servo, wählen Sie Echter Servo am Arduino-Board und einen Pin (z. B. D9). Schließen Sie den Servo so an: braun oder schwarz an GND, rot an 5V, orange oder gelb an den gewählten Pin. Logic schaltet diesen Pin in den Servomodus und sendet den Winkel des Arms auf dem Bildschirm. Siehe Lektion 44.

Ein kleiner Servo (wie der SG90 aus einem Starterkit) darf an den 5V des Boards. Ein größerer Servo bekommt eine eigene Versorgung; verbinden Sie dann den GND dieser Versorgung mit dem GND des Boards.

Klappt es nicht?

  • Kein Port gefunden: Stecken Sie das Board erneut ein und klicken Sie auf Ports suchen. Unter Windows schauen Sie im Geräte-Manager › Anschlüsse (COM & LPT).
  • Port kann nicht geöffnet werden: Schließen Sie die Arduino IDE (oder den seriellen Monitor); nur ein Programm gleichzeitig kann den Port benutzen.
  • Das Board antwortet nicht: Spielen Sie StandardFirmata (erneut) auf.
