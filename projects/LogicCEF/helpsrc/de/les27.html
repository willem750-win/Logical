Das Flipflop merkt sich etwas

Ziel: mit einem SR-Flipflop einen kurzen Druck auf einen Taster speichern, wie bei einem Alarm, der weiter läuft.

▶ Dieses Beispiel öffnen

Ein Gatter vergisst, ein Flipflop speichert

Bei einem Gatter hängt der Ausgang nur von den Eingängen jetzt ab. Lassen Sie den Taster los, geht die Lampe aus. Ein Flipflop hat einen Speicher von einem Bit: Der Ausgang Q bleibt 1 oder 0, auch wenn die Eingänge wieder ausgehen.

S (oberer Taster)R (unterer Taster)Q (LED)
00bleibt wie vorher
101 (Set)
010 (Reset)
11verboten; in Logic gewinnt R: 0
  1. Starten Sie die Simulation. Die LED ist aus: Ein neues Flipflop beginnt mit Q = 0.
  2. Drücken Sie kurz auf den oberen Taster (S). Die LED geht an und bleibt an, wenn Sie loslassen.
  3. Drücken Sie noch einmal auf S: Nichts ändert sich, Q ist schon 1.
  4. Drücken Sie auf den unteren Taster (R). Jetzt geht die LED aus und bleibt aus.

Ein Alarm

So funktioniert ein Alarm: Ein Türkontakt oder Bewegungsmelder gibt nur ein kurzes Signal auf S, aber die Sirene soll weiter heulen, bis jemand auf Reset drückt. Ersetzen Sie die LED ruhig durch einen Summer.

Aufgabe: bis drei zählen

Klicken Sie mit der rechten Maustaste auf das Flipflop und wählen Sie T. Jetzt wechselt Q bei jedem Druck auf den Taster: Das Flipflop teilt die Anzahl der Drücke durch zwei. Fügen Sie ein zweites Flipflop hinzu, auch vom Typ T. Wie verbinden Sie die beiden, damit zwei Lampen binär zählen: 0, 1, 2, 3 und wieder 0?

Lösung

Der Taster geht an T des ersten Flipflops. Sein Q geht an eine Lampe mit dem Wert 1. Sein Q̅ (nicht-Q) geht an T des zweiten Flipflops, und Q dieses zweiten Flipflops an eine Lampe mit dem Wert 2. Jedes Mal, wenn die erste Lampe von 1 auf 0 geht, geht Q̅ an und das zweite Flipflop wechselt: Das ist der Übertrag, genau wie beim Halbaddierer.

▶ Den Zähler öffnen

Speicher: Der Arbeitsspeicher eines Computers besteht aus Milliarden solcher Speicherzellen. Mit D-Flipflops speichert ein Prozessor Zahlen, mit T-Flipflops zählt er.
