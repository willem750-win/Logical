Speicher

Ziel: Zahlen an einer Adresse in einem Speicher ablegen und später wiederfinden, so wie es ein Computer tut.

▶ Dieses Beispiel öffnen

Adresse und Inhalt

Ein Speicher ist wie ein Schrank mit nummerierten Schubladen. Die Nummer einer Schublade ist die Adresse, was darin liegt, ist der Inhalt. Dieser Speicherbaustein hat 32 Schubladen (Adresse 0 bis 31), und jede Schublade enthält eine Zahl von 0 bis 15.

  • Der Zähler oben wählt die Adresse. Der untere Taster zählt eine Adresse weiter, der obere setzt auf 0 zurück (siehe Lektion 8). Die obere Anzeige zeigt die Adresse.
  • Mit dem DIP-Schalter stellen Sie eine Zahl ein (8, 4, 2, 1). Mit seinem Knopf schreiben Sie die Zahl in die gewählte Schublade.
  • Die untere Anzeige zeigt den Inhalt der gewählten Adresse.

Ausprobieren

  1. Starten Sie die Simulation. Die Adresse ist 0.
  2. Schalten Sie am DIP-Schalter 4 und 1 ein (= 5) und drücken Sie seinen Knopf. Die untere Anzeige zeigt 5.
  3. Zählen Sie eine Adresse weiter: Der Inhalt von Adresse 1 ist noch 0.
  4. Schreiben Sie dort eine andere Zahl hinein, zum Beispiel 9 (8 + 1).
  5. Setzen Sie den Zähler auf 0 zurück: Die Anzeige zeigt wieder 5. Der Speicher hat es sich gemerkt.

Übung

Legen Sie die Zahlen 3, 1, 4, 1 und 5 an den Adressen 0 bis 4 ab. Setzen Sie den Zähler danach auf 0 zurück und gehen Sie die Adressen durch. Lesen Sie die Zahlen in der richtigen Reihenfolge zurück?

Lösung

An jeder Adresse: Zahl am DIP-Schalter einstellen (3 = 2 + 1, 1 = 1, 4 = 4, 5 = 4 + 1), seinen Knopf drücken und dann mit dem Zähler eine Adresse weiter. Nach dem Zurücksetzen zeigt die Anzeige bei jedem Schritt die gespeicherte Zahl: 3, 1, 4, 1, 5.
