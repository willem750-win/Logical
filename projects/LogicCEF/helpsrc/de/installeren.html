Logic installieren

Logic ist kostenlos und läuft auf einem Windows-PC und unter Linux. Sie können es installieren oder, ohne Installation, einfach entpacken. Administratorrechte brauchen Sie nicht.

Herunterladen

Die neueste Version finden Sie auf SourceForge und auf GitHub. Wählen Sie die Datei für Ihren Computer:

ComputerDateiWas ist das?
WindowsLogic-<Version>-setup.exeInstallationsprogramm (empfohlen).
WindowsLogic-<Version>-win64.zipOhne Installation: entpacken und starten.
Linux (Debian, Ubuntu, Mint ...)logical_<Version>_amd64.debInstallationspaket (empfohlen).
Anderes LinuxLogic-<Version>-linux-x86_64.tar.gzOhne Installation: entpacken und starten.

Mac, Tablets und Smartphones werden nicht unterstützt.

Windows: installieren

  1. Doppelklicken Sie auf Logic-<Version>-setup.exe in Ihrem Ordner Downloads.
  2. Erscheint ein blaues Fenster Der Computer wurde durch Windows geschützt? Klicken Sie auf Weitere Informationen und dann auf Trotzdem ausführen. Windows zeigt diese Meldung bei Programmen, die noch nicht oft heruntergeladen wurden.
  3. Folgen Sie den Schritten des Installationsprogramms. Logic erscheint im Startmenü und, wenn Sie die Option ankreuzen, auf dem Desktop.

Eine neuere Version installieren Sie genauso, über die alte. Ihre eigenen Panels und Einstellungen bleiben erhalten.

Windows: ohne Installation (Zip)

Praktisch, wenn Sie nichts installieren dürfen, zum Beispiel auf einem Schullaptop, oder wenn Sie Logic auf einem USB-Stick mitnehmen möchten.

  1. Klicken Sie mit der rechten Maustaste auf Logic-<Version>-win64.zip und wählen Sie Alle extrahieren.... Wählen Sie einen Ordner, in den Sie schreiben dürfen, zum Beispiel Dokumente\Logic oder einen USB-Stick.
  2. Öffnen Sie den entpackten Ordner und doppelklicken Sie auf logicCEF.exe. Bei der blauen Meldung klicken Sie wieder auf Weitere Informationen und Trotzdem ausführen.
Achtung: starten Sie Logic nicht direkt aus der Zip-Datei, ohne sie zu entpacken. Dann kann Logic Ihre Panels nicht speichern und die Hilfe funktioniert nicht.

Linux

  1. Installieren Sie das Paket: Doppelklick auf logical_<Version>_amd64.deb (Software installieren) oder in einem Terminal:
    sudo apt install ./logical_<Version>_amd64.deb
  2. Starten Sie Logic aus dem Menü, unter Bildung, oder mit logical.

Ohne Installation: Entpacken Sie Logic-<Version>-linux-x86_64.tar.gz in Ihrem Home-Ordner und starten Sie ./logicCEF im entpackten Ordner.

Unter Linux öffnet sich die Hilfe in Ihrem normalen Browser.

Wo sind meine Panels?

Ein Panel, das Sie speichern, landet standardmäßig im Ordner panels von Logic:

Installiert mitOrdner
Windows-Installationsprogramm%LOCALAPPDATA%\Programs\Logic\panels
Zipder Ordner panels in dem Ordner, in den Sie Logic entpackt haben
Linux-Paket~/.local/share/logical/panels

Müssen Sie ein Panel abgeben? Speichern Sie es mit Speichern an einem Ort, den Sie leicht wiederfinden, zum Beispiel Dokumente, und schicken Sie diese .lpl-Datei.

Und dann?

Beginnen Sie mit Erste Schritte oder gleich mit der ersten Lektion des Lernpfads.
