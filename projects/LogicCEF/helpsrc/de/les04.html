Das UND-Gatter

Ziel: einen Ausgang erst dann arbeiten lassen, wenn alle Eingänge ein sind.

▶ Dieses Beispiel öffnen

Ein echtes Beispiel: die Zweihandbedienung

Eine Presse in einer Fabrik darf nur arbeiten, wenn der Bediener beide Knöpfe drückt, mit jeder Hand einen. So kann nie eine Hand unter der Presse sein. Das UND-Gatter macht genau das:

Linke Hand (A1)Rechte Hand (A2)Presse (Lampe)
000
010
100
111

Zwei Eingänge ergeben vier Möglichkeiten. Nur in der letzten Zeile ist der Ausgang ein.

Warum Schalter? An einer echten Presse sind es Taster. Mit einer Maus können Sie in Logic aber nur einen Knopf gleichzeitig gedrückt halten. Deshalb stellen hier zwei Schalter die beiden Hände dar.

Ausprobieren

Starten Sie die Simulation. Schalten Sie zuerst einen Schalter ein, dann den anderen, und beobachten Sie, wann die Lampe leuchtet. Gehen Sie so die vier Zeilen der Tabelle durch.

Übung

Die Presse darf erst arbeiten, wenn auch das Schutzgitter geschlossen ist: also drei Bedingungen. Ein UND-Gatter hat nur zwei Eingänge. Wie lösen Sie das?

Lösung

Verwenden Sie zwei UND-Gatter hintereinander. Das erste Gatter bekommt die beiden Hände. Sein Ausgang geht zusammen mit einem dritten Schalter (dem Gitter) zum zweiten UND-Gatter. Die Lampe hängt am zweiten Gatter: Sie leuchtet nur, wenn alle drei ein sind.

Mit einem echten Arduino-Board

Bauen Sie die Zweihandbedienung auch echt. In der Arduino-Version sind A und B zwei Arduino-Eingänge (Pin 2 und 3) und die Lampe ist ein Arduino-Ausgang (Pin 13).

▶ Arduino-Version öffnen

  1. Ziehen Sie das USB-Kabel ab und schließen Sie zwei Taster und eine LED wie im Plan an. Noch keine LED? Die kleine LED L auf dem Board hängt auch an Pin 13.
  2. Stecken Sie das Kabel wieder ein, verbinden Sie das Board in Logic (Arduino-Board) und starten Sie die Simulation.
  3. Drücken Sie einen Taster: Die LED bleibt aus. Drücken Sie beide gleichzeitig: Die LED leuchtet. So funktioniert eine echte Zweihandbedienung.
