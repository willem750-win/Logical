Programmieren mit LogicRun

Ziel: eine Ampel mit einem Programm statt mit Gattern und Drähten betreiben, so wie es ein kleiner Computer oder eine SPS tut.

▶ Dieses Beispiel öffnen

Was sehen Sie?

  • Den LogicRun-Block in der Mitte.
  • Links zwei Taster: der obere ist an DIN1 (Start/Stopp), der untere an DIN3 (+1).
  • Rechts drei farbige 5-V-Lampen mit zwei Klemmen wie eine Ampel: UIT0 rot (oben), UIT1 gelb (Mitte) und UIT2 grün (unten). Von jedem Ausgang führt ein Draht zur linken Klemme der Lampe und von der rechten Klemme der Lampe zur − Schiene.

Das Programm

Doppelklicken Sie auf den Block: das LogicRun-Fenster öffnet sich. Das Programm hat drei Schritte:

SchrittEinZeit xDauer (Schrittzeit 500 ms)
1UIT0 (rot)63 Sekunden
2UIT2 (grün)63 Sekunden
3UIT1 (gelb)21 Sekunde

Weil Wiederholen eingeschaltet ist, beginnt das Programm nach Schritt 3 wieder bei Schritt 1.

Probieren Sie es

  1. Starten Sie die Simulation und drücken Sie den oberen Taster: die Ampel beginnt zu laufen.
  2. Drücken Sie noch einmal: das Programm macht Pause. Drücken Sie dann einige Male den unteren Taster: bei jedem Druck geht das Programm einen Schritt weiter.
  3. Schauen Sie im Fenster mit: der aktuelle Schritt ist hellblau.

Aufgabe

Lassen Sie das grüne Licht 5 statt 3 Sekunden leuchten. Fügen Sie danach eine Fußgängerampel hinzu: eine grüne Lampe an UIT3, die nur leuchtet, wenn die Ampel rot ist.

Lösung

Bei einer Schrittzeit von 500 ms sind 5 Sekunden das 10-fache der Schrittzeit: setzen Sie Zeit x von Schritt 2 auf 10. Klicken Sie in Schritt 1 (rot) auch den Kreis von UIT3 an. Setzen Sie eine 5-V-Lampe mit zwei Klemmen auf das Panel (Rechtsklick › Spannung der Lampe › Lampe für 5 V (auch an einem Gatter)) und machen Sie eine grüne Lampe daraus (Rechtsklick › Farbe › Grüne Lampe). Legen Sie einen Draht von UIT3 zur linken Klemme der Lampe und von der rechten Klemme der Lampe zur − Schiene. So steuert ein einziges Programm mehrere Lampen gleichzeitig.
